# Obhod - обход блокировок для телефона

Требования:
- Android 11+
- Для стабильной работы в фоне разрешите приложению неограниченное использование батареи;
  автозапуск и названия настроек зависят от производителя телефона.

---

Obhod - гибрид [tg-ws-proxy-android](https://github.com/amurcanov/tg-ws-proxy-android) и [zapret](https://github.com/flowseal/zapret-discord-youtube) для телефона.

Для обхода блокировки телеграм через MTProxy используеться Rust подход из андроид версии tg-ws-proxy указаной выше. Когда как для обход других блокировок проходит через систему fake TLS от Zapret.

## Важная информация

Обход не обещает полного обхода всех блокировок стабильно, но он способен обойти большинство блокировок в зависимости от доступности.
DNS UDP/53 и TCP/53 сначала отправляется через DoH Cloudflare, Google или Quad9;
при повторных сбоях DoH временно пропускается, а запрос передаётся настроенному
системному DNS. DoH сначала подключается по IP без SNI, сохраняя проверку имени
в сертификате; при несовместимости повторяется обычное TLS-подключение с SNI.
Остальной UDP остаётся прямым: звонки Discord и другие UDP-сервисы
могут не работать. В профиле List
`quic_fallback` выключен, поэтому QUIC не блокируется принудительно.

Android VPN маршрутизирует IP, а не домены, поэтому весь трафик входит в TUN;
ядро применяет include-список и отправляет остальные домены напрямую.
